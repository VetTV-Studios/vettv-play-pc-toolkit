# Hardware notes

- **Intel HD 530 + GTX 960M (Asus)**: HD 530 is below the Intel UHD 630 class guideline. Set Google Play Games to the GTX 960M in Windows Settings > System > Display > Graphics > High performance. The 960M uses NVIDIA's legacy, security-only driver branch (582.xx): supported, but older.
- **AMD R9 M390 (iMac, Boot Camp)**: AMD no longer ships drivers. The toolkit reports "may not meet requirements" but never blocks you.
