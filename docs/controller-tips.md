# Controller tips

These are also shown in the app's **Controller tips** tab.

- **Built-in support**: Google Play Games on PC supports keyboard and mouse, and many games support controllers. Many games show a controls overlay (often Shift+Tab) with the key mappings.
- **Xbox / XInput controllers**: work best because games see them as standard gamepads. Connect the controller before launching the game.
- **PlayStation (DS4/DualSense)**: may not be recognized directly. Add the game to Steam (Launch tab > Add to Steam) and turn on Steam Input for that shortcut, or use DS4Windows to emulate an Xbox controller. Run only one remapper at a time.
- **Steam Input**: Steam > game > Properties > Controller > Enable Steam Input. Layouts can map buttons to keys for games without controller support.
- **Lenovo Legion Go / handhelds**: use the controller mode that presents an XInput gamepad, set Windows scaling to 100–150%, and plug in for the High performance preset.
- **MSI laptop**: if the keyboard's Win key lock (Fn+F-key on many MSI models) or MSI Center "Gaming mode" interferes with game shortcuts, toggle those off.
